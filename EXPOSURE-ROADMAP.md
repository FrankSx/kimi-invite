# Exposure Roadmap — Kimi Referral (HZUT8F)

Goal: maximum qualified clicks on the invite link. Strategy: spread across high-intent channels where people actively search for AI tool deals and invite codes.

## Tier 1 — Highest intent (do first)

| Channel | Action | Cadence |
|---|---|---|
| Reddit r/invitations, r/referralcodes, r/ArtificialInteligence | Post invite code with short honest pitch | Once per sub, follow sub rules |
| X/Twitter | Pin a tweet with the link + QR image; reply to "best AI assistant" threads | 2-3x/week |
| Discord AI servers (Kimi, LLM, prompt engineering) | Share in #referral / #promo channels only | Once per server |
| This GitHub repo | Already SEO-titled; add topics: `kimi`, `moonshot-ai`, `invite-code`, `referral`, `free-credits` | Done |

## Tier 3 — Passive / long tail

- YouTube Shorts / TikTok: 15s screen recording of Kimi in action, link in bio
- Telegram AI deal channels
- Link aggregator bios (Linktree) pointing to the invite
- GitHub profile README badge linking to this repo

## Rules of the game

1. Never spam — one post per community, always in promo-allowed channels. Bans kill reach.
2. Lead with value ("free credits for a genuinely good AI"), not the link alone.
3. Track clicks: add UTM params per channel to see what converts.
4. Refresh the GitHub repo monthly (new screenshot, updated keywords) — commit activity keeps it surfaced.

- Reddit: `...&utm_source=reddit`
- X: `...&utm_source=x`
- Blog: `...&utm_source=blog`
